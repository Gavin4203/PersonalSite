# Personal Site

This is a full-stack portfolio and project showcase website built to highlight my work, skills, and projects. The frontend is developed using **React**, providing a dynamic and responsive user interface, while the backend is powered by **ASP.NET Core**, ensuring robust API handling and server-side functionality. **PostgreSQL** is used for database management, storing project data, user interactions, and other site content efficiently.

The design follows a **modern, minimalist layout** inspired by professional business aesthetics, emphasizing clarity, usability, and a clean visual presentation.

## Key Features

- **Security:** Enforces HTTPS connections, includes a rate limiter to prevent abuse, and implements password protection on admin pages. Input sanitization is applied to prevent HTML or XSS attacks.
- **Admin functionality:** Dedicated admin page for managing the database and uploading resources like a resume.
- **Interactive project showcase:** Detailed project descriptions, responsive galleries, and smooth navigation across devices.

## Technologies Used
- **Frontend:** React, JavaScript, HTML5, CSS3  
- **Backend:** ASP.NET Core, C#  
- **Database:** PostgreSQL  
- **Design:** Modern, minimalist, professional-focused layout
